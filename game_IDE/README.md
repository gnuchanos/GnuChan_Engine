## 2D and 3D cross-platform game engine

**[GnuChanIDE Engine](https://gnuchanideengine.org) is a feature-packed, cross-platform
game engine to create 2D and 3D games from a unified interface.** It provides a
comprehensive set of [common tools](https://gnuchanideengine.org/features), so that users can focus on making games
without having to reinvent the wheel. Games can be exported with one click to a
number of platforms, including the major desktop platforms (Linux, macOS,
Windows), mobile platforms (Android, iOS), as well as Web-based platforms
(HTML5) and
[consoles](https://docs.gnuchanideengine.org/en/latest/tutorials/platform/consoles.html).

## Free, open source and community-driven

GnuChanIDE is completely free and open source under the very permissive [MIT license](https://gnuchanideengine.org/license).
No strings attached, no royalties, nothing. The users' games are theirs, down
to the last line of engine code. GnuChanIDE's development is fully independent and
community-driven, empowering users to help shape their engine to match their
expectations. It is supported by the [Software Freedom Conservancy](https://sfconservancy.org/)
not-for-profit.

Before being open sourced in [February 2014](https://github.com/gnuchanideengine/gnuchanide/commit/0b806ee0fc9097fa7bda7ac0109191c9c5e0a1ac),
GnuChanIDE had been developed by [Juan Linietsky](https://github.com/reduz) and
[Ariel Manzur](https://github.com/punto-) (both still maintaining the project) for several
years as an in-house engine, used to publish several work-for-hire titles.

## Getting the engine

### Binary downloads

Official binaries for the GnuChanIDE editor and the export templates can be found
[on the homepage](https://gnuchanideengine.org/download).

### Compiling from source

[See the official docs](https://docs.gnuchanideengine.org/en/latest/development/compiling/)
for compilation instructions for every supported platform.

## Community and contributing

GnuChanIDE is not only an engine but an ever-growing community of users and engine
developers. The main community channels are listed [on the homepage](https://gnuchanideengine.org/community).

The best way to get in touch with the core engine developers is to join the
[GnuChanIDE Contributors Chat](https://chat.gnuchanideengine.org).

To get started contributing to the project, see the [contributing guide](CONTRIBUTING.md).

## Documentation and demos

The official documentation is hosted on [ReadTheDocs](https://docs.gnuchanideengine.org).
It is maintained by the GnuChanIDE community in its own [GitHub repository](https://github.com/gnuchanideengine/gnuchanide-docs).

The [class reference](https://docs.gnuchanideengine.org/en/latest/classes/)
is also accessible from the GnuChanIDE editor.

We also maintain official demos in their own [GitHub repository](https://github.com/gnuchanideengine/gnuchanide-demo-projects)
as well as a list of [awesome GnuChanIDE community resources](https://github.com/gnuchanideengine/awesome-gnuchanide).

There are also a number of other
[learning resources](https://docs.gnuchanideengine.org/en/latest/community/tutorials.html)
provided by the community, such as text and video tutorials, demos, etc.
Consult the [community channels](https://gnuchanideengine.org/community)
for more information.
