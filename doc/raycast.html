⚡ RayCast 3D

GnuChanIDE — 3D fizik sahnesinde çizgi sorgusu: tüm API, Türkçe açıklamalarıyla

📋 Hızlı Referans

RayCast, 3D fizik sahnesinde bir başlangıç noktasından cast_to bitiş noktasına uzanan çizgiyi sorgular ve çizgiye değen ilk fizik gövdesini raporlar. Sonuç her fizik karesinde otomatik güncellenir. Çizginin uzunluğu: cast_to = Vector3(0, 0, -uzunluk) veya length özelliği. Bir gövdeyi/sahneyi sorgu dışı bırakmak için: skip(self) veya skip_group("duvar").

Dikkat: skip(), skip_group(), body_name(), body_group(), length — bu motorun RayCast'ine özel eklenen kolaylık fonksiyonlarıdır (orijinal Godot'ta yoktur).

🔍 Sorgu — Çizgi Ne ile Kesişiyor?

func is_colliding() -> boolÇekirdek
Sorgu çizgisi şu anda bir fizik gövdesiyle kesişiyor mu? Temel kontrol. Sonuç her fizik karesinde otomatik güncellenir.
if $Head/InteractionRay.is_colliding():
	# kesişim var, hedefle işlem yap
func get_collider() -> ObjectÇekirdek
Çizgiye değen fizik gövdesi node'unun kendisini döndürür. Dönüş tipi Object'tir ama pratikte sahnenizdeki gövde düğümüdür: StaticBody, KinematicBody, RigidBody veya Area. Kesişim yoksa null döner.
Bu Object, herhangi bir Node gibi davranır; yani üzerinde şunları yapabilirsin:
ad / tip: get_name(), get_class(), is_in_group("kapi")
etiket/metadata: get_meta("kapi_anahtari") — editörde node'a "Meta" olarak yazdığın değerler
script'e erişim: hedef.get("can") veya hedef.call("ac") — gövde üzerindeki GDScript değişken/metotları
ağaç işlemleri: get_parent(), get_node("CollisionShape"), queue_free(), set_visible(false)
var hedef = $Head/InteractionRay.get_collider()
if hedef != null:
	# 1) Türünü ve adını öğren
	print(hedef.get_class(), " -> ", hedef.get_name())   # StaticBody -> "Kapi1"

	# 2) Grupta mı kontrol et
	if hedef.is_in_group("kapi"):
		hedef.call("ac")          # gövdedeki script fonksiyonu

	# 3) Meta'ya göre karar ver (editörde "Meta" alanına yazılır)
	if hedef.has_meta("kilitli"):
		return  # kilitli kapı açılmaz
func get_collision_point() -> Vector3Çekirdek
Çizginin gövdeye değdiği nokta (küresel koordinat). Çarpma izi, patlama efekti veya işaretçi yerleştirmek için kullanılır.
# çarpma noktasına bir nesne yerleştir
var nokta = $Head/InteractionRay.get_collision_point()
func get_collision_normal() -> Vector3Çekirdek
Çarpma noktasındaki yüzeyin normal vektörü (yüzeye dik, gövdenin dışına bakan birim vektör). Yere serilen nesnenin dönüşünü hesaplamak, basamak/kuyu fiziği veya yüzeye hizalama yapmak için kullanılır.
func body_name() -> StringGnuChan Yeni
Çizgiye değen gövdenin node adını döndürür (ör. "Zemin", "Kapi"). Kesişim yoksa boş string.
print($Head/InteractionRay.body_name())  # > "Zemin"
func body_group() -> StringGnuChan Yeni
Çizgiye değen gövdenin ilk grubunun adını döndürür. Grup yoksa boş string.
if $Head/InteractionRay.body_group() == "kapi":
	# "kapi" grubundaki bir gövdeye değiyoruz

🚫 Atla / Hariç Tut — Sorgu Dışı Gövdeler

func skip(node: Node)GnuChan Yeni
Verilen node'u ve alt ağacındaki tüm fizik gövdelerini sorgu dışı bırakır. Kendi karakterini sorgu dışı bırakmak için _ready içinde skip(self) yeterlidir — FPSController bunu otomatik yapar.
func _ready():
	$Head/InteractionRay.skip(self)          # kendi karakteri
	$Head/InteractionRay.skip($Kapilar/Kapi1) # herhangi bir obje
func skip_group(group: String)GnuChan Yeni
Bir gruba üye tüm node'ların alt ağacındaki fizik gövdelerini sorgu dışı bırakır. "duvar" grubunu tamamen atlamak tek satır. Çağrı, node ağaç içindeyken yapılmalıdır (_ready sonrası).
func _ready():
	$Head/InteractionRay.skip_group("duvar")  # tüm "duvar" grubu

⚙️ Ayarlar — Sorgu Çizgisinin Geometrisi

prop cast_to: Vector3Çekirdek
Çizginin bitiş noktası (yerel koordinat). Vector3(0, 0, -5) → -Z yönünde 5 birim uzunluğunda sorgu.
$Head/InteractionRay.cast_to = Vector3(0, 0, -10)  # 10 birim menzil
prop length: floatGnuChan Yeni
Çizgi uzunluğunu tek bir sayı ile ayarlar; cast_to.z'yi otomatik olarak -length yapar. cast_to'nun kısayoludur.
$Head/InteractionRay.length = 3.0   # cast_to = (0, 0, -3)
print($Head/InteractionRay.length)   # > 3.0
prop enabled: boolÇekirdek
Sorgu açık/kapalı. Kapalıyken sonuç güncellenmez ve is_colliding() false döner.
prop collide_with_bodies: boolÇekirdek
Fizik gövdeleri (StaticBody, KinematicBody, RigidBody) sorguya dahil mi? Varsayılan açık.
prop collide_with_areas: boolÇekirdek
Area'lar (tetikleyici bölgeler) sorguya dahil mi? Varsayılan kapalı.
func force_raycast_update()Çekirdek
Sorguyu hemen bir kez çalıştırır. Fizik karesini beklemeden (ör. aynı karede gövde taşıdıktan sonra) güncel sonuç almak için kullanılır.
note collision_mask
GnuChan RayCast'inde katman maskesi sabit olarak tümü (0xFFFFFFFF) ayarlıdır. Gövdeleri dışlamak için maske yerine skip() / skip_group() kullanılır.

🧪 Debug — Çizgiyi Görselleştir

prop debug_shape_custom_color: ColorÇekirdek
Editör'de çizginin görsel rengi. Varsayılan debug rengini kullanır; özelleştirmek için renk ver. (Oyun içinde görünmez.)
prop debug_shape_thickness: intÇekirdek
Çizginin görsel kalınlığı (1-5). Görünürlüğü artırmak için kullanılır.
