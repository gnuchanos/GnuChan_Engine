GCL — GnuChan Language

GCL, GnuChan Engine'in oyun betik dilidir. C benzeri sözdizimine sahiptir; katmanlı tip sistemi, class bildirimleri, güvenli dizi yönetimi ve doğrudan node erişimi sunar.

Uzantı: .gcsf (script) · .gclib (kütüphane) · Derleme: py makefile.py -j8

İlk Betik

# GnuChan'da merhaba dünya
void Ready() {
    PrintF("Merhaba GnuChan! FPS: %d\n", Engine.GetFPS);
}

@return Metodu

class FATHER() {
    @return
    gcChar Call() {
        return "where are you";
    }

    @return
    int Age() {
        return 55;
    }
}

FATHER ThisFather = FATHER;
PrintF("%s\n", ThisFather.Call);   # parantezsiz çağrı
PrintF("%d\n", ThisFather.Age);    # 55

Kalıtım

class CHILD(FATHER) {
    void head(gcChar who) {
        gcChar name = who;
    }

    void talk() {
        PrintF("child talks!\n");
    }
}

CHILD ThisChild = CHILD("ali");
ThisChild.talk();
PrintF("%s\n", ThisChild.Call);   # miras: FATHER.Call

@extern & Node Erişimi

Erişim Kuralı

self. → @extern node'unun orijinal parametreleri (Position, Name, GetNode, Free).

self.Raycast. → Raycast node'una gider; sonrası o node'un parametreleri.

self.Raycast.GetNode → raycast'in tuttuğu node.

Otomatik Tamamlama

self. (FPSController)
MoveSpeed, DuckSpeed, RunSpeed, JumpHeight, Gravity, IsRunning, Raycast, Camera, Head
self. (Spatial)
Position, Rotation, Scale, GetNode, Find, Hide, Show, Free, Enable, Disable
self.Raycast.
IsColliding, GetBodyName, length, Skip, SkipList, GetNode, Free
self.Camera.
Fov, MouseSpeed, HeadBob, HeadBobSpeed, HeadBobAmount, RunFovChange, GetNode
Input.
IsPressed, IsUp, IsDown
Engine.
GetFPS, SetFPS, GetScreenSize, GetWindowSize
Yanlış Kullanımlar

self.Material ❌ · self.Name ❌ · self.Childs ❌ · self.GetChild ❌

Doğrusu: self.GetNode("..."). veya self.GetNode("...").Find("x").

Örnek

NODE REF = GetNode("araba");

REF.GetChild.Find("ali").Free
REF.GetChild.Find("ali").Hide
REF.GetChild.Find("ali").Show
REF.GetChild.Find("ali").Disable
REF.GetChild.Find("ali").Enable

if (self.Raycast.IsColliding) {
    printf("Body: %s\n", self.Raycast.GetBodyName);
}
